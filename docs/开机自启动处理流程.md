# 开机自启动问题处理流程（SOP v3）

> 适用于：处理 Windows 开机自启动相关问题（关闭/删除/排查自启项、卸载残留自启、开机慢优化）
> 版本：v3（2026-08-17，含授权确认硬性步骤）

## 核心原则（必须先遵守）

1. **"询问" ≠ "授权"**——用户说"什么情况/看看/为啥自启"只是询问，只能诊断分析，**禁止**发起任何写操作
2. **先征询后操作**——AI 主动建议删除时，必须列出清单文字询问，用户明确回复确认后才动手
3. **每删必备份**——所有操作位置都要备份，备份放持久位置（桌面/文档），可恢复
4. **删后必查残留**——Run 键之外还要查同名服务/计划任务/文件残留（卸载残留典型场景）
5. **汇报含恢复路径**——误删后用户能自己找回

## 第 1 步：收集启动项清单（只读，Tier 1）

```powershell
# ① 注册表 Run 键（3 个位置）
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' | Format-List
Get-ItemProperty 'HKLM:\Software\Microsoft\Windows\CurrentVersion\Run' | Format-List
Get-ItemProperty 'HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Run' | Format-List
# ② 注册表 RunOnce（下次登录执行一次，HKCU + HKLM）
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\RunOnce' | Format-List
Get-ItemProperty 'HKLM:\Software\Microsoft\Windows\CurrentVersion\RunOnce' | Format-List
# ③ 启动文件夹（用户 + 公用）
Get-ChildItem "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup" | Select Name
Get-ChildItem "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp" | Select Name
# ④ 计划任务（开机/登录触发）
Get-ScheduledTask | Where-Object {$_.Triggers.CimClass.CimClassName -match 'Boot|Logon'} | Select TaskName
# ⑤ 自动启动服务（可选）
Get-Service | Where-Object {$_.StartType -eq 'Automatic' -and $_.Status -eq 'Running'} | Select Name, DisplayName
```

## 第 2 步：分析标注（只读）

- 每项标注：🟢 系统必需（ctfmon、安全软件、驱动） / 🟡 常用软件（QQ、钉钉、飞书） / 🔴 可关闭（更新器、残留、弹窗） / ⚠️ 可疑（未知路径/异常发布者）
- 可疑项查证：文件路径存在性 + 数字签名 `Get-AuthenticodeSignature`
- ⚠️ 本步只输出分析 + 建议清单，**绝不执行任何写操作**

## 第 3 步：授权确认（硬性门槛）

**两种方式二选一，缺一不可执行写操作：**

- **A. 用户主动明确指示**：用户原话点名（如"删除 XXX""把这些关掉"）→ 记录用户原话作为授权依据
- **B. AI 建议征询**：AI 列出拟删除清单 → 文字询问"是否执行？" → 用户明确回复（"是/删除/执行"）→ 才进入第 4 步

**禁止场景**：
- 用户只说"什么情况 / 看看 / 为啥会自启" → 只答分析，禁止发起任何写操作（也不弹审批窗）
- 用户没回复确认 → 禁止操作

**审批弹窗**（执行前最后确认）：必须显示人话说明"将删除【XXX】的开机自启项"（human_desc），不能只显示命令原文

## 第 4 步：处理（Tier 3，每处操作前先备份）

```powershell
# ① 备份（覆盖所有操作位置，放桌面持久保存）
reg export 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' "$env:USERPROFILE\Desktop\run-backup-YYYYMMDD.reg" /y
reg export 'HKLM:\Software\Microsoft\Windows\CurrentVersion\Run' "$env:USERPROFILE\Desktop\run-hklm-backup-YYYYMMDD.reg" /y
reg export 'HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Run' "$env:USERPROFILE\Desktop\run-wow64-backup-YYYYMMDD.reg" /y
# 启动文件夹 .lnk → 复制到桌面 backup 目录
# 计划任务 → Export-ScheduledTask -TaskName 'XXX' > 桌面备份

# ② 删除（按位置）
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'XXX'
Remove-ItemProperty -Path 'HKLM:\...\Run' -Name 'XXX'   # HKLM 需管理员（bridge 已提权）
Remove-Item "$env:APPDATA\...\Startup\XXX.lnk" -Force
Disable-ScheduledTask -TaskName 'XXX'

# ③ 卸载残留联动检查（MuMu 教训）：同名服务 / 计划任务 / Program Files 残留
Get-Service | Where-Object {$_.Name -like '*关键字*'}
Get-ScheduledTask | Where-Object {$_.TaskName -like '*关键字*'}
```

## 第 5 步：验证（只读，Tier 1）

1. 重新读取全部清单（第 1 步命令）→ 确认目标项已消失
2. 再查关联位置（同名服务/计划任务/文件残留）→ 确认无残留
3. 确认保留项未误删（ctfmon 等系统必需项）
4. 汇报：
   - 剩余启动项清单
   - 已删除清单
   - 备份文件位置（桌面 .reg / backup 目录）
   - **误删恢复方法**：`reg import 备份文件` / 复制回 .lnk / `Enable-ScheduledTask`
