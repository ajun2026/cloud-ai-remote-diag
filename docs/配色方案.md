# 配色方案留档 — GitHub Dark（当前基准）

> 生成：2026-08-30（配色切换前的基准留档——切换后可凭此恢复）
> 应用范围：clouddiag.online 全站（工作台/对话页/登录页/IDG 日志分析/管理后台）

## 主题名称

**GitHub Dark**（GitHub 官方暗色主题——#0d1117 经典深黑底）

## 色板（完整参数）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#0d1117` | 主背景（最深） |
| `--surface` | `#161b22` | 容器/卡片/侧边栏 |
| `--surface2` | `#21262d` | 次级表面（输入框/悬浮/选中底） |
| `--border` | `#30363d` | 边框/分隔线 |
| `--text` | `#e6edf3` | 主文字（近白） |
| `--text2` | `#8b949e`（index）／`#9da7b3`（dashboard） | 次要文字/说明 |
| `--info` | `#58a6ff` | 强调/链接/信息蓝 |
| `--accent` | `#f778ba`（仅 index 对话页） | 强调粉（快捷工具/高亮） |
| `--success` | `#3fb950` | 成功/在线绿 |
| `--warn` | `#d29922` | 警告/待处理琥珀 |
| `--error` | `#f85149` | 错误/危险红 |

## 辅助色（固定值——未变量化）

| 色值 | 用途 |
|---|---|
| `#1f6feb` | 按钮 hover / 激活 tab 边框 |
| `#f0f6fc` | 标题亮白（IDG h1 等） |
| `#e0a800` | 警告提示文字（连接面板等） |
| `#6e7681` | ID 弱化灰（IDG job-id） |
| `#484f58` | 文件 tab 关闭按钮灰 |

## 各文件变量定义位置

| 文件 | 说明 |
|---|---|
| `static/dashboard.html` | :root 完整（--text2 用 #9da7b3） |
| `static/index.html` | :root 完整（--text2 用 #8b949e + 多 --accent #f778ba） |
| `static/login.html` | 深色背景（#0d1117 系） |
| `templates/analyze.html`（IDG） | 部分硬编码（#161b22 背景/#0d1117 tab 激活/#30363d 边框）——未变量化 |
| `templates/upload.html`（IDG） | 纯色 #0d1117 背景 |
| `server.py`（管理后台生成页） | :root 变量（同 GitHub Dark） |

## 硬编码清单（切换主题时需处理——当前暗色下正常）

- IDG analyze.html：`.header`/`.sidebar` 背景 `#161b22`、tab 激活 `#0d1117`、边框 `#30363d`、`#21262d`（tab 底）
- IDG upload.html：`background: #0d1117`
- index.html 内联：`#e0a800`（警告）、`#2ecc71`（在线绿）
- dashboard.html 内联：`#58a6ff` 等（部分内联样式）

## 恢复方法（切回 GitHub Dark）

```
① :root 变量值按上表恢复
② 硬编码色值按「辅助色/硬编码清单」恢复
③ 无其他依赖（全站统一）
```

## 备注

- 切换主题（未来）：`:root[data-theme="light"]` 等方式——不改变 UI 布局/结构——仅换色
- 此文档为基准留档——主题切换后如需恢复——以此为准
