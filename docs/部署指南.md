# 部署指南（cloud-ai-remote-diag v0.13.11）

> 云端 AI 远程运维助手——部署到自己的服务器/Linux 机器
> 本文档从零开始，覆盖：环境 → 安装 → 配置 → 启动 → HTTPS → 常见问题

---

## 1. 环境要求

```
- Linux（Ubuntu 20.04+/Debian 10+ 均可；Windows 服务器不推荐）
- Python 3.10+
- 公网可达（服务器需要有公网 IP 或内网穿透——客户机要连回来）
- 建议 2C4G 以上（AI 对话 + WebSocket 并发）
```

## 2. 获取源码

```bash
git clone https://github.com/ajun2026/cloud-ai-remote-diag.git
cd cloud-ai-remote-diag
```

（或下载 ZIP 解压）

## 3. 安装依赖

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 4. 配置 .env（必须）

```bash
cp .env.example .env 2>/dev/null || vi .env   # 无示例则手动创建
```

`.env` 最小配置：

```ini
# ── AI 大脑（对话诊断必配；不配则登录/工具/房间可用，AI 对话不可用）──
OPENAI_API_KEY=你的DeepSeek或兼容网关APIKey
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat

# ── 部署地址（不配则自动从浏览器 Host 推导——一般不用填）──
# PUBLIC_URL=https://你的域名

# ── 管理后台（/admin）──
ADMIN_USERNAME=admin
ADMIN_PASSWORD=改成强密码

# ── 可选：Hermes 大脑通道（默认 deepseek 即可，不配）──
# AGENT_BRAIN=deepseek
```

## 5. 启动

```bash
python server.py
```

- 首次启动自动创建数据库 + 种子账号
- 默认监听 `0.0.0.0:8000`
- 验证：浏览器访问 `http://服务器IP:8000/login`（或 `curl http://127.0.0.1:8000/api/health` → `{"status":"ok",...}`）

## 6. 首次登录

```
种子账号（首次启动自动创建）：
  admin    密码 admin（请立即改）
  test1~test10  密码同账号名
```

改 admin 密码：登录后 → 修改密码页；或直接改 .env 的 ADMIN_PASSWORD 后重启。

## 7. HTTPS（强烈建议——生产必须）

```
默认 http 明文——密码/令牌/诊断数据会裸奔——生产必须 HTTPS

推荐 Caddy（自动证书）：
  1. 安装 Caddy
  2. Caddyfile：
     your.domain.com {
         reverse_proxy 127.0.0.1:8000
     }
     https://your.domain.com:8443 {   # 备用端口（部分网络拦 443）
         reverse_proxy 127.0.0.1:8000
     }
  3. 域名 A 记录指向服务器 IP——Caddy 自动申请 Let's Encrypt 证书
```

## 8. 客户端连接（桥接器）

```
登录系统 → 创建房间（SN + 工单号）→ 对话页/引导页有一键连接命令
→ 在客户机执行 → bridge 自动连接服务器（ws）→ 房间上线

客户机要求：Windows 10/11 或 Linux；能访问部署地址的 443/8443 端口
```

## 9. IDG 日志分析（可选——独立子应用）

```
「📊 IDG 日志分析」功能依赖独立仓库（不在主仓库内）：
  https://github.com/ajun2026/file-analyzer-web（Log Analyzer 日志诊断分析平台）
```

部署（可选——不需要此功能可跳过）：

```bash
git clone https://github.com/ajun2026/file-analyzer-web.git /opt/log-analyzer
cd /opt/log-analyzer
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python main.py        # 默认 127.0.0.1:8002

# ⚠️ 硬编码路径：detectors.py 里 BASE_DIR = Path("/opt/log-analyzer")
#    换目录需改此文件（或软链到 /opt/log-analyzer）
```

主服务接入路由（server.py 已内置反向代理——默认 `http://127.0.0.1:8002`）：

```bash
# .env 可改上游地址（默认即可）
# LOG_ANALYZER_UPSTREAM=http://127.0.0.1:8002
```

- 账号隔离：读取主系统登录 cookie——各账号只见自己的上传；admin 可查看全部
- 未部署时：工作台"IDG 日志分析"页签显示 404——属正常（可选功能）

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 登录提示"用户名或密码错误" | 确认账号存在（首次启动种子）——或查 logs/server.log |
| AI 对话无响应 | 检查 .env 的 OPENAI_API_KEY/BASE_URL 是否有效 |
| 客户机连接失败 | ① 确认服务器公网可达（443/8443 通）② 换 8443 备用端口 ③ 检查防火墙 |
| 80 端口访问异常 | 国内服务器未备案域名 80 被拦截——用 443/8443 |
| 忘记 admin 密码 | 改 .env 的 ADMIN_PASSWORD 重启；或删 chat.db 重新种子（会丢数据） |
| 登录 5 次失败被锁 | 安全限流（15 分钟自动解锁） |

## 10. 目录说明

```
server.py            主服务（FastAPI + WebSocket + AI 大脑）
static/              前端页面 + 工具包（tools/ 下：tslog/SMART/RAID 等）
data/                知识库（蓝屏停止码/坏驱动）
docs/                文档
logs/                运行日志（chat.db 会话数据库）
```

