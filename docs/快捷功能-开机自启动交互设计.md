# 快捷功能：开机自启动交互设计（方案 B 详细版）

> 版本：v1.0（2026-08-17）
> 目标：对话页提供「快捷功能」按钮区，首个功能=开机自启动查询与交互式关闭

## 一、整体架构

```
对话页（index.html）
  ├─ 快捷功能按钮区（输入框上方，可扩展）
  ├─ 启动项面板（特殊消息渲染：可勾选列表）
  ├─ 对话流（AI 执行过程 + 结果汇报）
  └─ 审批弹窗（执行前最后确认，人话）
        │
        ▼
服务器（server.py）
  ├─ 识别 QUICK_ACTION 指令 → AI 按 SOP 执行
  ├─ startup_list 消息类型（结构化下发）
  └─ approvals 记录（审计留痕）
        │
        ▼
桥接器（bridge，执行查询/删除命令）
```

## 二、快捷功能按钮区

### 位置与样式

```
┌───────────────────────────────────────────────┐
│ [🔌 开机自启动] [🩺 系统体检] [🌐 网络诊断]  ← 一排小按钮   │
│                                               │
│ （对话消息区）                                  │
│                                               │
│ （输入框）                                      │
└───────────────────────────────────────────────┘
```

- 按钮：小号、描边、悬停高亮（风格同「📶 连接你的电脑」）
- 仅 bridge 已连接时可用（未连接点击 → 提示"请先连接客户机"）
- 本期只实现「开机自启动」，其余按钮占位隐藏（框架预留）

### 点击行为

```
点击 [🔌 开机自启动]
  → 对话区出现系统消息："正在查询本机开机自启动项..."
  → 发送预置指令：{type:'chat', content:'[QUICK_ACTION:startup_scan]'}
  → AI 收到指令 → 按 SOP 第 1 步执行查询
```

## 三、消息协议

### 3.1 查询结果（服务器 → 前端）

```json
{
  "type": "startup_list",
  "items": [
    {
      "name": "BaiduYunDetect",
      "display": "百度网盘",           // 人话名称（AI 识别）
      "command": "C:\\Users\\justwar\\AppData\\Roaming\\baidu\\BaiduNetdisk\\YunDetectService.exe",
      "location": "HKCU\\Run",          // 来源位置
      "category": "advisory",           // necessary(🟢) / common(🟡) / advisory(🔴) / suspicious(⚠️)
      "recommend": true                 // 是否预勾选（advisory=true）
    },
    { "name": "ctfmon", "display": "系统输入法", "category": "necessary", "recommend": false }
  ]
}
```

### 3.2 关闭指令（前端 → AI）

```
{type:'chat', content:'[QUICK_ACTION:startup_close] {"names":["BaiduYunDetect","QuarkUpdater"]}'}
```

### 3.3 执行结果（服务器 → 前端）

```json
{
  "type": "startup_result",
  "closed": ["BaiduYunDetect", "QuarkUpdater"],
  "failed": [],
  "backup": "C:\\Users\\justwar\\Desktop\\run-backup-20260817.reg"
}
```

前端收到后：从面板移除已关闭项 + 对话区显示汇总消息。

```
┌─────────────────────────────────────────────┐
│ 开机自启动项（共 15 项）                        │
│ ─────────────────────────────────────────── │
│ ☐ ctfmon          系统输入法        🟢 必需    │
│ ☐ QQNT            QQ               🟡 常用    │
│ ☑ BaiduYunDetect  百度网盘         🔴 建议关闭 │
│ ☑ QuarkUpdater    夸克浏览器更新器  🔴 建议关闭 │
│ ☐ 汽水音乐         音乐软件         🟡 常用    │
│ ⚠️ UnknownSvc      未知程序         ⚠️ 可疑    │
│ ...（滚动，最多显示 30 项）                     │
│ ─────────────────────────────────────────── │
│ [✔ 关闭所选]  [全不选]   已选 2 项             │
│ 备注：🔴 为建议关闭项（已预勾选）                │
└─────────────────────────────────────────────┘
```

### 交互规则

| 项 | 规则 |
|---|---|
| 预勾选 | `recommend=true`（🔴 建议关闭）默认勾选；🟢🟡⚠️ 默认不勾 |
| 勾选操作 | 点击行切换勾选（整行可点） |
| 关闭所选 | 至少勾选 1 项才可点；点击弹确认框 |
| 确认框 | 人话列出全部勾选项 + "执行前自动备份" + [确认/取消] |
| 取消全选 | 清空勾选 |
| 面板生命周期 | 收到新 startup_list 替换旧面板；关闭所选后等待结果 |
| 无结果 | 查询失败/无启动项 → 显示"未获取到启动项" |

## 五、AI 执行流程（严格走 SOP v3）

```
收到 [QUICK_ACTION:startup_scan]
  → 查询全部位置（Run×3 + RunOnce×2 + 启动文件夹×2 + 计划任务）
  → 识别人话名称 + 分类标注
  → 返回 startup_list（结构化）

收到 [QUICK_ACTION:startup_close] {"names":[...]}
  → 校验：用户已通过面板勾选+确认（授权依据）
  → 备份：全部相关位置 reg export → 桌面
  → 删除：按 location 对应命令执行（Tier 3，弹审批——人话：将删除【百度网盘】自启项）
  → 残留检查：同名服务/计划任务/文件
  → 验证：重读清单确认消失
  → 返回 startup_result + 对话汇报（剩余/已删/备份/恢复方法）
```

**授权链（三道）**：
1. 面板勾选 + 确认框 = 用户明确选择
2. 审批弹窗（人话）= 执行前最后确认
3. approvals 表留痕 = 审计

## 六、前后端改动清单

| 端 | 文件 | 改动 |
|---|---|---|
| 前端 | index.html | ① 快捷功能按钮区（HTML+CSS）② handleMessage 加 `startup_list`/`startup_result` case ③ 面板渲染+勾选交互 JS ④ 确认框（复用审批弹窗风格）⑤ i18n 新增文案 |
| 后端 | server.py | ① 识别 `[QUICK_ACTION:startup_scan]` 预置指令（agent 提示词注入 SOP 流程）② 定义 startup_list 结构化下发（现有 ws send 机制）③ 记录 approvals（复用现有） |
| 文档 | docs/ | 本次设计文档存档 |

**说明**：查询/删除命令由 AI agent 通过现有工具（run_powershell/RunCommand）执行——**无需改 bridge**；前端只是把 AI 返回的工具输出转成结构化列表（AI 在消息里返回 JSON 或前端解析 tool 输出）。

## 七、安全与边界

| 项 | 设计 |
|---|---|
| 无连接保护 | bridge 未连接 → 按钮禁用 + 提示 |
| 系统必需保护 | 🟢 项不可勾选（面板里灰显）——防误删 ctfmon |
| 可疑项处理 | ⚠️ 不预勾选，AI 在汇报中提示查证 |
| 数量限制 | 面板最多 30 项（超出提示分批） |
| 授权强制 | 勾选+确认框+审批弹窗 三道，缺一不执行 |
| 审计 | approvals 表记录（工具/参数/批准人/时间） |

## 八、扩展机制（后续功能复用）

```
QUICK_ACTION 指令表：
  startup_scan / startup_close   → 开机自启动（本期）
  health_scan                    → 系统体检（占位）
  network_diag                   → 网络诊断（占位）
  disk_clean                     → 磁盘清理（占位）
每个功能 = 预置指令 + AI 提示词 + 面板渲染规则（可插拔）
```
