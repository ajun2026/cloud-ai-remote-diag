# 一键连接方案（桥接器唯一化下载）

|:---|:---|

---

## 一、目标

创建房间后，在**对话页/房间页**直接获取**预填房间码**的连接方式：复制即用、双击即连，无需手动输入房间码和服务器地址。

## 二、交互流程

```
工程师创建房间 → 进入对话页 → 看到「连接你的电脑」区块
    ├─ PowerShell 命令（复制一行，粘贴执行）
    ├─ Windows exe 下载（.bat 双击即连）
    └─ Linux 一键命令（复制执行）
```

每个连接方式**唯一**：预填该房间码，并标记 SN / 工单 / 工程师账号。

## 三、三种客户端实现

| 客户端 | 实现 | 用户操作 |
|---|---|---|
| PowerShell | 现有 ps1 已支持 `$env:BRIDGE_ROOM`，生成：`$env:BRIDGE_ROOM="XXXXXXX"; iex (iwr http://地址/static/bridge.ps1).Content` | 复制 → 粘贴执行 |
| Windows exe | 生成预填参数 .bat：`bridge-win64.exe -room XXXXXXX`（同目录），或直接下载 exe + 提示 `-room` 参数用法 | 下载 .bat + exe → 双击 .bat |
| Linux | 一键脚本支持房间码参数：`bash <(curl -s http://地址/static/install-linux.sh) XXXXXXX`（脚本增加参数解析） | 复制 → 执行 |

## 四、唯一性标记

生成内容带：
- 房间码
- SN / 工单号 / 机器型号
- 工程师账号 / 创建时间
- 提示：`请勿转发此脚本/命令（含房间凭证）`

## 五、技术改动清单

| 位置 | 改动 |
|---|---|
| server.py | 新增 `GET /api/room_connect/{room_code}`：返回该房间的三种连接内容（鉴权：仅房间所属工程师/管理员） |
| 前端 dashboard.html 对话页 | 房间打开时显示「连接你的电脑」区块，调用接口渲染三段内容 + 复制按钮 |
| install-linux.sh.tmpl | 增加房间码参数解析（$1 或环境变量） |
| 文档 | 使用说明更新 |

## 六、安全注意

- 预填脚本含房间码 = 凭证，前端提示"请勿转发"
- 接口鉴权：仅房间创建者/管理员可获取
- 房间码本就是轻量凭证（8 位，随用随建）

## 七、验证

1. 三个客户端各实测一次：复制即连、心跳正常、命令可执行
2. 非房间所属账号访问接口 → 拒绝
3. 管理员可看任意房间连接信息
