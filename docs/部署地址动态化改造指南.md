## B1. 部署地址动态化（server.py）

目标：仓库零硬编码，服务器地址由 `.env` 的 `PUBLIC_URL` 决定，未配置则从请求 Host 自动推导。

### B1.1 新增两个工具函数（放在 `static_dir` 定义之后）

```python
def get_public_url(request: Request) -> str:
    """部署地址：.env 的 PUBLIC_URL 优先，未配置则从请求 Host 自动推导。"""
    configured = os.getenv("PUBLIC_URL", "").strip().rstrip("/")
    if configured:
        return configured
    scheme = request.headers.get("x-forwarded-proto", request.url.scheme)
    return f"{scheme}://{request.headers.get('host', 'localhost:8000')}"

def get_ws_url(request: Request) -> str:
    """由 public_url 推导 WebSocket 地址（http→ws, https→wss）。"""
    return get_public_url(request).replace("https://", "wss://").replace("http://", "ws://")
```

### B1.2 脚本模板动态渲染（替换原 /static/bridge.ps1 硬编码路由）

```python
_SCRIPT_TEMPLATES = {
    "bridge.ps1": "text/plain; charset=utf-8",
    "install-linux.sh": "text/x-shellscript; charset=utf-8",
}

async def _render_script(script_name: str, request: Request) -> Response:
    tpl_path = static_dir / f"{script_name}.tmpl"
    if not tpl_path.exists():
        return JSONResponse({"error": f"template {script_name}.tmpl missing"}, status_code=500)
    content = tpl_path.read_text(encoding="utf-8")
    content = content.replace("{{PUBLIC_URL}}", get_public_url(request)).replace("{{WS_URL}}", get_ws_url(request))
    return Response(content=content, media_type=_SCRIPT_TEMPLATES[script_name])

# ⚠️ 必须用精确路径（不能 /static/{script_name} 通用路由）——通用路由会拦截
#    mount("/static") 下的全部静态资源（exe 等），导致下载 404。
# ⚠️ 必须注册在 app.mount("/static", ...) 之前——Mount 是前缀匹配，先注册会吞掉全部请求
@app.api_route("/static/bridge.ps1", methods=["GET", "HEAD"], include_in_schema=False)
async def static_bridge_ps1(request: Request):
    return await _render_script("bridge.ps1", request)

@app.api_route("/static/install-linux.sh", methods=["GET", "HEAD"], include_in_schema=False)
async def static_install_linux(request: Request):
    return await _render_script("install-linux.sh", request)
```

### B1.3 新增 /api/config 接口

```python
@app.get("/api/config", include_in_schema=False)
async def api_config(request: Request):
    return {"public_url": get_public_url(request), "ws_url": get_ws_url(request)}
```

### B1.4 页面模板注入（_html_file 改造 + 三个页面路由传 request）

```python
def _html_file(name: str, request: Request = None, no_cache: bool = True) -> HTMLResponse:
    html_path = static_dir / name
    if html_path.exists():
        headers = {"Cache-Control": "no-cache, no-store, must-revalidate"} if no_cache else None
        content = html_path.read_text(encoding="utf-8")
        if request is not None:
            content = content.replace("{{PUBLIC_URL}}", get_public_url(request)).replace("{{WS_URL}}", get_ws_url(request))
        return HTMLResponse(content, headers=headers)
    return HTMLResponse(f"<h1>Missing static/{name}</h1>")

# 三个页面路由：login_page(request)、dashboard_page、chat_page 均传 request
```

## B2. 脚本模板化（static/ 下 2 个文件）

### B2.1 static/bridge.ps1 → static/bridge.ps1.tmpl

复制原文件改名为 `.tmpl`，将 3 处地址替换为占位符：

```
原第 10 行注释:  iex (iwr http://106.54.193.9:8000/static/bridge.ps1).Content
   →  iex (iwr {{PUBLIC_URL}}/static/bridge.ps1).Content
原第 13 行注释:  $env:BRIDGE_ROOM = "ABC12345"; iex (iwr http://106.54.193.9:8000/static/bridge.ps1).Content
   →  $env:BRIDGE_ROOM = "ABC12345"; iex (iwr {{PUBLIC_URL}}/static/bridge.ps1).Content
原第 29 行运行时默认: $ServerUrl = ... { "ws://106.54.193.9:8000" }
   →  $ServerUrl = ... { "{{WS_URL}}" }
```

删除原 `bridge.ps1`（下载路由已由 B1.2 接管）。

### B2.2 static/install-linux.sh → static/install-linux.sh.tmpl

```
第 6 行注释:  curl -sL http://{{PUBLIC_URL}}/static/install-linux.sh | bash
第 17 行:    SERVER="http://{{PUBLIC_URL}}"
第 94 行:    bridge -server {{WS_URL}} -room 房间码
```

## B3. 前端地址占位符化（static/ 下 2 个 HTML）

统一替换规则（**注意：PUBLIC_URL 本身含协议，不要再加 http:// 前缀**）：

```bash
# index.html（7 处，均为 http://IP:8000）
sed -i 's|http://106.54.193.9:8000|http://{{PUBLIC_URL}}|g' static/index.html
# 修正为（避免双协议）
sed -i 's|http://{{PUBLIC_URL}}|{{PUBLIC_URL}}|g' static/index.html

# dashboard.html（3 处 http + 1 处 ws）
sed -i 's|ws://106.54.193.9:8000|{{WS_URL}}|g; s|http://106.54.193.9:8000|http://{{PUBLIC_URL}}|g' static/dashboard.html
sed -i 's|http://{{PUBLIC_URL}}|{{PUBLIC_URL}}|g' static/dashboard.html
```

## 注意事项（踩过的坑）

| 坑 | 说明 |
|:---|:---|
| 通用路由吞静态文件 | `/static/{script_name}` 通用路由会让 exe 下载 404，必须用精确路径 |
| Mount 顺序 | 脚本路由必须注册在 `app.mount("/static")` 之前 |
| 双协议 | PUBLIC_URL 自带协议，模板里写 `{{PUBLIC_URL}}/path`，不能写 `http://{{PUBLIC_URL}}` |
| Content-Type | bridge.ps1 必须 `text/plain; charset=utf-8`（PowerShell 5.1 iwr 把非文本当 Byte[]） |
| GET/HEAD 双测 | curl -sI（HEAD）单独测会假阴性，GET+HEAD 都要测 |
