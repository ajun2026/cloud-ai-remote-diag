# 访问排障指引（打不开 clouddiag.online 时）

> 文档用途：管理员复制给打不开的用户/工程师
> 说明：80 端口入口页方案已取消（未备案域名 80 被腾讯云拦截）——统一引导 8443

---

## 第一步：用备用地址

```
https://clouddiag.online:8443
```

- 正常网络：`https://clouddiag.online`（443）可用
- 443 打不开（公司网络/防火墙拦截）：**直接用 8443**——同一套系统、同一账号

## 第二步：如果 8443 也打不开

按顺序试：

| # | 操作 |
|---|---|
| 1 | 换浏览器：Chrome / Edge（不要用老版 IE） |
| 2 | 关闭代理 / VPN（公司代理最常见导致） |
| 3 | 清 DNS 缓存：Win+R → 输入 `cmd` → 回车 → 输入 `ipconfig /flushdns` |
| 4 | 杀毒软件把 clouddiag.online 加入白名单（或关闭 HTTPS 扫描） |
| 5 | 换网络试试（手机热点）——热点能开 = 公司网络拦截，联系 IT 放行 |

## 说明（管理员用）

- **为什么 443 打不开**：部分公司网络/运营商防火墙对 443 端口的 TLS 握手做深度检测（SNI），检测到就重置连接（浏览器报"连接被重置"PR_CONNECT_RESET_ERROR / 无法建立安全连接）
- **8443 是什么**：备用 TLS 端口（同一张证书）——绕过"只拦 443"的防火墙策略
- **为什么不做 80 入口页**：域名未备案——80 端口被腾讯云拦截（显示备案提示页）——无法用于入口
- 一键连接命令/连接包已内置自动降级（443 探测失败自动切 8443）——连接客户机不受影响
